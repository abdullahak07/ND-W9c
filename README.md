# COMP6013 Week 9 — Network Endpoint Security

A Vercel-ready interactive lecture website built from the Week 9 lecture deck.

## Design
- Lots of short information visible directly on the page
- Deeper detail hidden behind in-place **flip playcards**
- Firewall foundations, firewall types, packet-filter attacks, IDS, malware, malware defense, incident management, forensics and DDoS
- Quick checks after each major module
- 7-question final quiz with immediate feedback
- Responsive, no build step, no external dependencies

## Deploy
Import this repository into Vercel and deploy as a static site. No build command is required.
